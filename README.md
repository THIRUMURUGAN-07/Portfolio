## 🌐 Deployment Instructions

### Option 1: GitHub Pages (Recommended - Free & Easy)
1. Push this code to a public GitHub repository (e.g. `portfolio` or `THIRUMURUGAN-07.github.io`).
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/THIRUMURUGAN-07/portfolio.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings** -> **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` branch and `/ (root)` folder, then click **Save**.
5. Your portfolio site will be live at `https://THIRUMURUGAN-07.github.io/portfolio/`!

---

### Option 2: Vercel (Instant 1-Click Deployment)
1. Visit [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New Project** and select your `portfolio` repository.
3. Keep default settings (Framework Preset: **Other**) and click **Deploy**.
4. Vercel will deploy your live portfolio link instantly!

---

### Option 3: Netlify (Drag & Drop Deployment)
1. Visit [netlify.com](https://www.netlify.com) and log in.
2. Go to **Sites** -> **Add new site** -> **Deploy manually**.
3. Drag and drop the `portfolio` folder into the Netlify drop zone.
4. Your website will be live in seconds!
